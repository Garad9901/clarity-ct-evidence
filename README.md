# CLARITY-CT evidence repository

Evidence behind the focused narrative review "Explainable Artificial Intelligence for Chest CT in 2025 and 2026".

| Folder | Contents |
|---|---|
| records/ | Every opened record: included (selected.json + gandomkar_2022_ref85.json), not included (excluded.json, excluded_reasons.csv), per-theme search results, per-reference notes (final_meta.py) |
| charting/ | The 27-study evidence map (table3_charting.csv). Columns coder_A_category and coder_B_category are for two authors coding independently |
| verification/ | Claim-citation check inputs and verdicts |
| figures/ | Figure scripts and current figure files |
| supplement/ | Online Resource 1 source (LaTeX) |
| manuscript_v1_ai_drafted/ | The earlier draft written by an AI tool. Reference only. NOT FOR SUBMISSION |
| PROVENANCE.md | Where every number in the paper comes from |
| CLAIM_LEDGER.csv | Every claim, its evidence and its status (measured or planned) |
| project_log.md | Dated log of working sessions, written by the authors |

No patient data, credentials or personal data beyond the published author lists of cited papers are stored here.
